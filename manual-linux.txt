Permisos, usuarios y grupos.

Para listar el contenido de un directorio o carpeta
tenemos que utilizar el comando ls

A su vez, con la bandera -l podemos ver con más detalles
los permisos y otros datos de los archivos y carpetas
el comando sería ls -l

lo que se lista con la bandera -l es:
primera columna - permisos
segunda columna - número
tercera columna - quién es el dueño del archivo o directorio
cuarta columna - grupo dueño del archivo o directorio

primera columna
-rw-rw-r--

primer elemento -
indica el tipo de archivo (cuando es - es un archivo)
d indica que es un directorio

segundo elemento
los siguientes caracteres (los tres siguientes al primer elemento)
rw- nos indican cuáles son los permisos del dueño del archivo

tercer elemento
los siguientes tres nos indican cuáles son los permisos del grupo
rw-

cuarto elemento
los últimos tres r--
nos indican los permisos de otros usuarios que no son el dueño
ni nadie perteneciente al grupo


r = permisos de lectura Read
w = permisos de escritura Write
x = permisos de ejecución
- = no se tiene el permiso


CREAR UN NUEVO GRUPO
comando sudo groupadd nombreGrupo

CREAR USUARIOS
sudo adduser nombreUsuario
contraseña para usuario creado
información del usuario

AÑADIR USUARIO A UN GRUPO
sudo adduser nombreUsuario nombreGrupo

CAMBIAR DE USUARIO O LOGEAR POR TERMINAL
su nombreUsuario
contraseña del usuario

CAMBIAR GRUPO AL QUE PERTENECE UN ARCHIVO
comando: chgrp nombreGrupo nombreArchivo.extensión

LEER CONTENIDO DE ARCHIVO
usamos cat para leer el archivo en terminal

ESCRIBIR CONTENIDO EN UN ARCHIVO
echo texto a escribir nombreArchivoDestino.extensión

CAMBIAR PERMISOS DE UN USUARIO
chmod 
se puede utilizar un código de números para añadir o modificar
permisos
en binario se remite a 1 para cuando hay un permiso y 0 cuando no
habría que hacer la "traducción" del binario a números
rw- = 666 (código para dar permiso de lectura y escritura, pero no
de ejecución)
chmod 666 archivo.extensión

COMANDO PARA BORRAR ARCHIVOS Y DIRECTORIOS
usamos rm nombreArchivo.extensión para borrar un archivo
cuando tenemos un directorio, hay que agregar la bandera -r
de recursivo, quedando el comando rm -r nombreCarpeta

PROTOCOLO SSH
es un protocolo que permite una conexión remota segura entre dos máquinas
con una estructura cliente-servidor

en ambas máquinas tiene que haber un cliente ssh instalado

tenemos que saber la ip de la máquina destino y algún usuario que haya en
dicha máquina destino

openssh - desde termina
cliente putty - es un entorno gráfico que también permite ser usado desde 
windows

para instalar cliente openssh en linux
sudo apt-get install openssh-client

REALIZAR CONEXIÓN REMOTA
ssh nombreUsuario@numeroDeIPdelHostRemoto
ssh maxi@192.168.0.77

nos va a salir un mensaje diciendo que no conocemos la autenticidad del host
remoto y le tenemos que indicar que si, para añadir ese host a la lista
de host conocidos
Luego nos pide una contraseña para acceder al host y tenemos que poner
la contraseña del usuairo al que queremos conectarnos

Ahora ya podremos trabajar con ese nuevo usuario como si estuviéramos en él

Para salir de la sesión colocamos exit
y volveremos a tener el prompt de nuestra pc


CONEXIÓN SSH CON PUTTY
sudo apt-get install putty

luego por terminal escribimos putty y se abrirá el cliente gráfico

introducimos el ip del host remoto y el puerto
guardamos la sesión con un nombre
luego load y open
aceptamos y listo
