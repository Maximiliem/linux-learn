Permisos, usuarios y grupos.

Para listar el contenido de un directorio o carpeta
tenemos que utilizar el comando ls

A su vez, con la bandera -l podemos ver con más detalles
los permisos y otros datos de los archivos y carpetas
el comando sería ls -l

lo que se lista con la bandera -l es:
primera columna - permisos
segunda columna - número
tercera columna - quién es el dueño del archivo o directorio
cuarta columna - grupo dueño del archivo o directorio

primera columna
-rw-rw-r--

primer elemento -
indica el tipo de archivo (cuando es - es un archivo)
d indica que es un directorio

segundo elemento
los siguientes caracteres (los tres siguientes al primer elemento)
rw- nos indican cuáles son los permisos del dueño del archivo

tercer elemento
los siguientes tres nos indican cuáles son los permisos del grupo
rw-

cuarto elemento
los últimos tres r--
nos indican los permisos de otros usuarios que no son el dueño
ni nadie perteneciente al grupo


r = permisos de lectura Read
w = permisos de escritura Write
x = permisos de ejecución
- = no se tiene el permiso

DETECCIÓN DE MEMORY LEAKS CON VALGRIND

Qué es un memory leak?
Significa pérdida de memoria o filtrado de memoria.
Ocurre cuando un proceso gestiona mal la memoria y afecta a los programas 
escritos en C o C++

El caso típico es cuando escribimos un programa que reserva memoria
dinámicamente y no la libera (usando la función free())

Es difícil de detectar, ya que puedo escribir el programa, ejecutar el proceso
dejarlo corriendo varias horas o días y hasta bastante pasado el tiempo
no sea visible el problema. Al cabo de cierto tiempo empezarán a fallar
ciertos procesos del sistema.
Se comienza a consumir recursos de memoria muy altos que otros programas 
necesitan.

Qué es valgrind?
Detectan errores en el manejo de memoria de un programa.

ACL - ACCESS CONTROL LIST - LISTAS DE CONTROL DE ACCESO
Sirve para configurar permisos de usuarios y grupos sobre archivos y directorios

Comandos:
getfacl - para listar y ver los permisos que hay
setfacl - para asignar o quitar permisos

getfacl archivo_ejemplo
lista los permisos para user (owner), group, other.

sudo setfacl -m g:grupo_1:rw archivo_ejemplo
esto significa:
-m para modificar
g indica grupo, pero puede ser u para user, mask para la máscara (que son los
permisos máximos a tener, que no afecta a root y other), o para other users 
:grupo_1 es el nombre del grupo
:rw son los permisos que se otorgan
archivo_ejemplo es el archivo destino de los permisos

Para aplicarlo en un directorio 
sudo setfacl -R -m g:grupo_1:rw dir_1/

esto significa
-R que es recursivo y afecta a todo lo de dentro del directorio
-m que modifica
también se podía haber escrito como -Rm
g: para grupo
grupo_1 para nombre del grupo
:rw los permisos de lectura y escritura asignados
dir_1/ es el directorio destino de esa moficiación

COMANDOS BÁSICOS DE MANIPULACIÓN DE ARCHIVOS Y DIRECTORIOS

sabemos que con ls listamos los contenidos del directorio
con la flag/opción -letra podemos acceder a más funciones de ls
* ls -l lista un formato largo en donde se indican permisos de los
archivos y documentos
* ls -a lista archivos y carpetas ocultos en adición a los que ya
son visibles de manera normal con ls
* ls -la combina el formato largo y muestra además archivos ocultos

mkdir - significa make directory y sirve para crear carpetas
ejemplo de uso: mkdir Carpeta1

rmdir - sirve para eliminar el directorio que se desee
ejemplo de uso: rmdir Carpeta1

cp es el comando para copiar y debemos indicar el archivo o 
carpeta a copiar y el destino (que el destino puede ser otro archivo
o un nuevo directorio) 
en caso de copiar un archivo, es importante poner la extensión
correcta del archivo
ejemplo de uso: cp documento document1.txt (siendo que el documento
original es un .txt)

en acso de copiar una carpeta o directorio tenemos que hacer -r
porque indica que es recursivo y nos copia todo lo que hay bajo
el directorio
ejemplo de uso: cp -r Course CopiaCourse

cp -a Curso Curso2
esto permite copiar absolutamente todo lo que haya en la carpeta
origen
copia permisos, directorios, archivos, absolutamente todo

la gran diferencia de la copia recursiva -r y la -a es que
la recursiva puede dejarse algunas cosas en camino sin copiar

en una copia recursiva, puede fallar la copia de una carpeta vacía

WILDCARDS - COMODINES
sirve para hacer referencia a algo que no conocemos o más de una
cosa

*
?

el * hace referencia a archivos que comienzan con lo que queramos
por ejemplo si quisiéramos ver solo los archivos .md de una
carpeta que tiene 5 archivos (4 son .md y 1 .txt)
ls *.md 

por ejemplo si quisiéramos ver todos los archivos que comienzan
por 03 (por ejemplo), sabiendo que hay un archivo llamado
03-curso-programacion-1.txt
lo podemos buscar de dos maneras

ls 03* y nos va a buscar todos los archivos y carpetas que 
empiecen con 03 sin importar lo que siga después o bien le podemos
indicar que finalicen de alguna manera como una extensión
ls 03*.txt
en ese caso veremos el archivo 03-curso-programacion-1.txt

esto es porque el * hace referencia a 0 o más caracteres
--
el ? hace referencia a un número exacto de caracteres
tenemos que utilizar le ? haciendo referencia a algo concreto

si tuviera un archivo que se llame a.txt para encontrarlo con ?
debería hacer esto: ls a????
por qué son 4 los ? -> porque el punto y la extensión son caracteres
y luego de la a hay 4 caracteres.
En caso de tener un archivo que se llame ar.txt no lo vamos a ver
ya que los caracteres que se siguen de la a son r.txt y son 5

otra forma de encontrar el archivo a.txt sería saber que termina
en .txt y que solo sabemos que el nombre del archivo es 1 caracter
entonces hacemos ls ?.txt
ya que de esta manera estamos indicando exactamente el número de 
caracteres
--
los comodines no solamente sirven para listar, también se pueden
usar con otros comandos como rm

si tuviéramos 2 archivos a.txt y b.txt podríamos hacer
rm ?.txt y nos estaría eliminando ambos archivos

LECTURA DE ARCHIVOS
cat -> muestra el contenido del archivo por pantalla y es útil
para archivos de pequeña extensión

para tener más control sobre lo que visualizamos en pantalla 
podemos usar el comando less que nos permite paginar el contenido
es decir, no se despliega de una todo el fichero o archivo en
pantalla

para salir de la visualización de less hay que presionar q

básicamente less abre un visor para el documento

comando more -> nos da visualización del documento con menos
funcionalidades que less

comando head -> nos muestra las primeras 10 líneas del archivo
y más nada, es una especie de preview del documento.

puedo manipular la cantidad de líneas que quiero visualizar con
head con la flag -n y el número de líneas
head -n 20 archivo.txt

también podemos ver el final del documento con el comando tail
también aplica el -n 20 para tail
tail archivo.txt
tail -n 20 archivo.txt

LOGS con tail
podemos ver el final constantemente con tail -f file.log
para visualizar constantemente el final del documento, ya que los
logs siempre guardan al final del todo los últimos registros

BÚSQUEDAS DENTRO DE ARCHIVOS GREP
sirve para buscar patrones en archivos o en salidas de otros comandos

grep "texto a buscar" archivo.extensión
nos devuelve en patanlla todas las líneas en donde aparece aquello
que buscamos

grep -i "Palabras" archivo.txt
va a ignorar que "Palabras" está en mayúsculas
hace que no sea case sensitive

búsquedas recursivas con grep
grep -r "palabra" CarpetaAbuelo/carpetaPadre/carpetaHijo

buscará la palabra o palabras indicadas de forma recursiva
en todo el directorio y sub directorios
podemos concatenar con -i para que no detecte mayúsculas

comando wc 
wc archivo.txt
wc -l cuenta las líneas del archivo
wc -w cuenta las palabras del archivo
wc -c cuenta de los bytes que pesa el archivo

se pueden concatenar varias flags

REDIRECCIÓN Y PIPES
vamos a empezar a trabajar con la salida de los comandos o
encadenar comandos mediante símbolos de < y >

Redirección
>
>>
<

ejemplo redirección simple:
echo "Hola" > hello.txt
guarda el texto en el archivo indicado
tiene sobreescritura

para almacenar más texto sobre un archivo que ya tiene texto
previamente

echo "pan" >> hello.txt
añade el texto al final
es importante saber que no admite símbolos ya que nos puede mostrar
un mensaje en pantalla de evento no encontrado

combinar tree con >>
podríamos hacer que la salida del comando tree se guarde en el 
archivo hello.txt

para tomar de entrada el contenido de un fichero o archivo <
podemos ordenar contenido ya almacenado de esta manera
habiendo guardado la salida del tree en el archivo hello.txt
aplicamos:
sort < hello.txt
y automáticamente nos ejecuta en pantalla el sort (ordena) 


PIPES |
es esa barra |
sirve para concatenar diferentes comandos
cat archivo.txt | grep "palabra" | wc -w
esto nos devolvería la cantidad de palabras que coinciden con
"palabra" dentro del archivo.txt

VARIABLES DE ENTORNO
echo $HOME
echo $PATH

se pueden definir variables a nivel de sistema y a nivel local

definir variable local:
name="variable"
acabamos de definir una variable en la sesión del zsh o bash que es
variable, aunque el nombre es name
echo $name
devuelve variable
solamente será visible esa variable en la sesión del bash en donde
fue definida, porque fue declarada en la sesión esa y no en la
de la nuev terminal (o nueva sesión)

hay variables globales como $PATH que se guardan a nivel del SO
para poder guardar variables a nivel global:
export NOMBRE="Variable Global"

para que esa variable exportada sea visible por todas las 
sesiones de bash, tenemos que acceder al fichero de la 
bash_profile y añadir allí el export VARIABLE="valor"
de esta manera hacemos persistente la variable
